## 1. 问题：三个抱怨，一个根因

作者原话：

1. 「失焦模式对玩家通关没什么关系」——像"我能在方块不断突变的情况下击败末影龙吗"这样的快餐题材；
2. 「玩家没有明确的目标」+「容易造成在基地里待到死」；
3. 「失焦会让珍贵的矿物块获取变得非常简单，而结束失焦后反而不行了」。

| 抱怨 | 机制上的根因 | 证据 |
|---|---|---|
| ① 失焦与通关无关 | 四个动词里只有**建造/破坏**有机制支撑；**观察**没有产出、**利用**只改落点、不改"是否发生" | `DESIGN.md` §13.3 自己标了 ⚠️；§14.6 |
| ② 没有目标 / 龟缩 | (a) 候选体的进度单位是"见过多少方块"（Pokédex），不是"理解了多少"；(b) 稳定系统与进度**同向**——越接近胜利越安全 | §13.5、§14.8 |
| ③ 矿物失衡 | **不是 `wild_chance`，是两件更硬的事**：<br>(a) **幽灵可挖**——挖幽灵方块拿的是**幽灵的掉落**（§5.2），所以"失焦"本身就是一条采矿路径；<br>(b) **概念跨 tier**——`focal_decay:concept/ore` 里同时有 `coal_ore` 和 `netherite_block` | §5.2；`src/generated/resources/data/focal_decay/tags/block/concept/ore.json` |

> (b) 这一条决定了护栏**必须加在"池"这一层**：把 `wild_chance` 压到 0 也没用——
> 只要引导模型的概念是 `ore`，抽中的目标就可能是下界合金块。
> （该概念 33 条目标里，`raw_*_block` / `*_block` / `amethyst_block` / `quartz_block` / `netherite_block` 全在。）

## 2. 主轴：三条规则

**R1 —— 词汇即样本。**
你能说的概念，只能来自你收集过的东西。想让它产原木，你得先见过足够多种木头。
**没有菜单，只有词汇表。**

**R2 —— 形可变，量不减。**
你能决定它**变成什么**，但不能减少**变化的总量**。每一次定向失焦，都在附近制造你控制不了的失焦。
基地与工作区永远不可能同时是堡垒——**语义锁定越小越便宜，基地是研究站，不是掩体。**

**R3 —— 阶段 3 开始，你的词会失效。**
后期不是"概率更高"，而是**概念本身开始漂移**：你训练的概念被世界重新解释。
你要原木，它给你"原木这个意思"的别的东西。
**恐怖从世界转移到你自己的词汇上**——而因为你已经投入了大量训练，这一刀才会真的疼。

> 这三条把四个动词补成闭环：**采集（观察）→ 概念（理解）→ 定向失焦（操纵）→ 固化收获（固定）**，
> 而每一步都在改变世界本身。R1 治"与我无关"，R2 治"龟缩"，R3 治"快餐"。

### O-1 tier 怎么赋值（作者点名要讨论）

| 候选 | 做法 | 代价 |

> **需要你定的**：接受"原版工具门槛 = 文明进度"这个隐喻吗？

### O-2 tier 之间怎么转（作者点名要讨论）

| 候选 | 规则 | 后果 |
|---|---|---|
| **A（推荐）** | **只降不升**：`tier(target) ≤ tier(source)` | 见下三条 |
| B | 相邻可升可降：`|Δtier| ≤ 1` | 石头(T0) → 铁矿(T1) 仍然可行 → 抱怨③只减弱一半 |
| C | 只降不升 + 概念内部例外 | 现状已满足，不需要例外 |

**A 的三条后果**：
1. 失焦**永远不产矿**（石头 T0 只能变 T0）→ 抱怨③ 的 (a) 那一半直接消失；
2. **矿脉会自己烂掉**（钻石矿 T2 → 金矿/红石矿，仍是 T≤2）→ 新的恐怖来源，
   也让**语义锁定第一次有了非抽象的用途：护住你的矿脉**；
3. 同 tier 内仍然错位，所以"挖矿"这个动词保住（你得先真的挖到，不能等它变出来）。

**为什么推荐 A**：它同时解决三件事——矿物护栏、语义锁定的存在理由、主题自洽。
`DESIGN.md` §13.4 的原话就是「失焦产生的是**错位**，不是**价值**」；A 是这句话的机械形式。

> **需要你定的**：接受"矿脉会自己烂掉"吗？这是 A 最刺眼的一条。

### O-4 定向失焦的两级形态与成本（作者 §六，也是第一刀）

| | **形式一：催化域** | **形式二：沉降仪式** |
|---|---|---|
| 定位 | **工具** | **产能** |
| 载体 | 已有的稳定锚原型机 + 装在上面的引导模型 | 同一原型机的"大型仪式"模式（多方块结构留到后期） |
| 动作 | 界面上按"催化"（或用专用道具右键） | 投入**成本**，等待 N 秒，期间必须留在附近 |
| 范围/时长 | 半径 = 模型半径，持续 K 个周期 | 半径 R 的**球体**（R 由投入量决定） |
| 产出 | 区域内可突变方块在该周期内全部变为该概念成员（一片"原木田"） | 球内方块按投入物所属**概念**确定性分布 |
| 时长/中断 | 即时 | 复用 `ThroneRitualHandler` 状态机：CONTINUE / PAUSE / FAIL + 波次 + 进度持久化 |
| 代价 | ① 催化期间该区域**不能同时受保护**；② 域外一圈 `wildChance` 升高且持续更久 | 投入物本身 + 仪式期间该区域失焦加剧 + 重聚焦后成本 ×K |

**与 tier 的关系（关键）**：自然失焦只降不升（O-2 A）；**沉降仪式是唯一的升 tier 通道，代价就是成本。**
于是"必须先在世界里找到钻石"这个门槛被替换成**经济门槛 + 理解门槛**：

> 想产出一球铁矿 → 投入铁一级的材料 + 该概念 `q ≥ 0.75`。
> **你不需要"见过"它，你需要"付得起"并且"理解到位"。**

这直接回答了作者对"先找到钻石才会失焦出钻石"的顾虑（操作难度高）——它从 checklist 变成了一次生产决策。

**为什么它不是印钞机**：产出总量受**投入价值预算**约束，默认**不盈利**；
盈利只能来自"引导准确 + 时运 + 规模化"，这正是把它做成**产业**而不是彩票的意思。数量差需要实机定数。

> **需要你定的**：① 仪式载体先做"原型机模式"还是直接做多方块结构；
> ② 投入物粒度（锭 / 块）；③ 重聚焦后的成本倍数 K；④ 半径与投入量的关系曲线。

### O-5 阶段 3 的惩罚（取代 `guided_stage3_halve`）

**现状**：`GuidedConcept.effectiveQ` 在阶段 3 把 q × 0.5（配置 `guided_stage3_halve`，默认开）。
因为 q 直接乘在"抽中引导池"的概率上，**玩家的训练投入一夜之间打对折**——作者判为"粗暴、努力报废"。

**推荐：保留强度，改换语义。** 用连续的**概念漂移率** `drift` 取代折半：

```
drift      = clamp(阶段 3 内的进度, 0, 1) × MAX_DRIFT      // 从 0 连续爬升
引导池     = (1 - drift) × 概念池 + drift × 邻域概念池
q / 强度   不变
界面显示    「完备度 87% · 漂移 43%」
```

四条理由：① 不是断崖；② 不报废努力（q 还是满的，只是**意思**漂了）；
③ 给玩家行动空间（趁漂移还小赶紧用掉，或先做完仪式）；④ **比"砍半"恐怖得多**——
`DESIGN.md` §13.2 要的后期情绪是「我认得的东西开始不可信了」，而这里不可信的是**你自己的词汇**。
这条同时是 `DESIGN.md` §14.3「阶段推进：概率变高 vs 规则被侵蚀」的答案（选"规则被侵蚀"）。

> **需要你定的**：`MAX_DRIFT` 的上限（建议 0.5，留一半是准的）；阶段 3 内是线性还是曲线。

### O-6 q 的四级解锁各解锁什么（R1 的具体化）

建议每一级给一个**新的动词或新的规模**，而不是数字：

| q | 能力 | 动词 |
|---|---|---|
| ≥ 0.25 | 该概念下的漂移在画面上被标出来 | 看得见 |
| ≥ 0.50 | 可触发**催化域**（小半径） | 让它变 |
| ≥ 0.75 | 可做**沉降仪式** | 让它产出 |
| = 1.00 | 催化时可**点名**概念里的某一种方块 | 说了算 |

> **需要你定的**：这四级是否合适。
> 另需注意：现在 `q = 已记录成员 / 概念总数`，所以**概念越大越难满**——
> `focal_decay:concept/*` 只有 6 个策展概念（glass / ore / stone / terracotta / wood / wool），
> 其余靠原版标签兜底，两者规模差很大。要不要给"大概念"另一条达标路径，是个待定项。

### O-7 主线接缝与通关门槛

- 建议顺序：首次训练 → 概念完备 → 铜块突变 / 王座 / 核心 → 末影龙（碎片·Aaron）→ OBSR-EX → 王座仪式 → 重聚焦。
- 候选体的进度单位改成"理解了多少概念"之后，§14.8 的"在出生点右键 100 个方块就能通关"**自动消失**
  （概念要求你去不同的地方）。配合"未完成候选体不再给完全稳定"（§3 第 2 条），绕行路径彻底关闭。
- 碎片七感官放在 P2 期（`BACKLOG` P2-6g）。

> **需要你定的**：**通关需要多少个概念**（现在是 100 个唯一方块）；碎片七感官是否确认放在 P2。

### O-8 tier 护栏与"跨 tier 的概念"会互相干扰（本次读标签时发现）

- **事实**：`focal_decay:concept/ore` 的成员**横跨全部四个 tier**——
  `coal_ore`(T0) 与 `netherite_block`(T3) 在同一个概念里（共 33 条条目）。
- **于是 O-2 的"只降不升"与概念系统会打架**：源方块是 T0 的石头、引导概念是 `ore` 时，
  池里被 tier 规则过滤之后**一个目标都不剩**——玩家花很久训练的 `ore` 概念，
  在石头地面上**完全无效**，而且他不会知道为什么。
- 三个候选：

| 候选 | 做法 | 代价 |
|---|---|---|
| **1（推荐）** | **按 tier 拆概念**：`ore/t0`（煤）/ `ore/t1`（铁、铜、青金石）/ `ore/t2`（金、红石、钻石、绿宝石）/ `ore/t3`（下界合金、远古残骸） | 概念总数变多，O-7 的通关门槛要重算 |
| 2 | **概念按源分层**：概念不变，"这个概念在这个源 tier 上意味着什么"由 tier 规则推出（T0 源 → 只有煤） | 训练一次到处能用；代价是同一个概念的含义随源变化，解释成本高 |
| 3 | **引导/催化豁免 tier 上限**（自然失焦仍受 O-2 约束） | "训练出 `ore` 概念"本身成了升 tier 的钥匙；它比仪式便宜得多，**会让沉降仪式失去意义** |

- **推荐 1**：它把"你理解了多少"这件事**分层**，与 O-1 的工具门槛是同一条轴，
  而且让"理解"第一次有了台阶（先理解煤，再理解铁……）——正好补上 R1 缺的那个"逐渐"。
- 好消息：`wood` / `wool` / `glass` / `terracotta` 这些 T0 概念**不受影响**，
  R1 的核心体验（"我要一片原木田"）在"只降不升"下依然完全成立。

## 6. 验收标准（第一刀 = P0）

- `[sync]` 段新增断言：**翻转催化域 → 两端解析结果跟着变**，并做 A/B（故意不翻转，断言必须 FAIL）；
- 新增 `[tier]` 段断言：池里不存在 `tier(target) > tier(source)` 的组合（A/B 同样要求）；
- `[实机]` 石头区放好概念 + 触发催化 → **≥90% 的可突变方块在同一周期内变成该概念成员**（目视 + 截图）；
- `[实机]` 催化后域外一圈的漂移明显增多（R2 的代价可观测）；
- `[联机]` 同一区域、同一周期，两台机器逐位相同的目标（§3.2）；
- `[手册]` 把"哪些东西会失焦、哪些不会"与 tier 规则写清（P1-1b 的验收也有这一条）。

## 7. 工程代价与硬约束

- **新增状态全部必须进同步**（§3.2 是最高优先级不变量）：催化域、漂移率、仪式序号。
  凡加一个客户端要用的值，先问"客户端怎么知道它"。
- **可以复用的**（已读代码确认，不是推测）：
  - `MutationPoolManager.PrototypeEffect(center, radius, data, concept)` + 整表/增量同步 + 客户端镜像
    （`ClientRegionData.guidedModels`）——催化域是它的第三个字段，不是新管线；
  - `ThroneRitualHandler` 的状态机（CONTINUE / PAUSE / FAIL + 波次 + 进度持久化）——仪式直接复用；
  - `MutationHelper.resolveInternal(..., chance, wildChance, periodIndex, ...)` 里**"是否发生"就是 `chance` 一个 double**
    （`if (MutationRandom.toDouble(state) >= chance) continue;`）→ 区域级 chance 覆盖**不需要新的判定分支**；
  - 回扫用的是 `MutationRandom.seed(pos, worldSeed, period)`，纯函数 → 催化**不破坏"两端逐位一致"**，
    也**不需要逐方块存档**。
- 沉降仪式的球体分布同样建议做成 `(pos, worldSeed, 仪式序号)` 的纯函数：可回放、可测、不落盘。
